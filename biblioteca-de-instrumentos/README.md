# Instrumentos

231 fichas con motor, 34 entradas conservadas como código y 27 referencias
documentales (incluyen variantes). No son 292 instrumentos únicos.

`fichas/` describe los sonidos; `motores/` los interpreta; `codigo/` conserva las
fuentes necesarias y su procedencia. `referencias.json` enlaza las familias que
viven bajo `research/rejilla/` y los cuatro paquetes externos.

Para listar: `python biblioteca-de-instrumentos/tomar.py --lista` desde la raíz.
Para exportar fichas, consulta `tomar.py --help`.

Se omiten muestras, renders y documentos binarios. Algunas fuentes originales
y README históricos hacen referencia a entregas o recursos omitidos. Las 27
altas documentales aún no tienen adaptador común. Los cuatro scripts externos
conservan rutas del entorno donde nacieron: requieren adaptación.
